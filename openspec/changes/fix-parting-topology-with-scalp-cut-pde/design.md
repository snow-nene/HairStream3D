## Context

当前三维 screened-Poisson 在完整体素邻接图上求解，发缝内部界面仅增加有限权重的法向分量惩罚。RK4、二维侧别投影、SDF 碰撞、guide 拉拽和根部吸附随后独立修改轨迹，因此发缝拓扑和根部贴附均不是贯穿链路的不变量。详细数学分析见 `docs/PDE_PARTING_TOPOLOGY_SOLUTIONS_AND_SMOKE_PLAN.md`。

项目以单张 front 为默认输入，发缝 mask 只对可见区域可信；隐藏后冠端点必须使用有限长度先验并携带置信度。实现必须复用 pixi 环境，测试输出和真实样例输出分别遵守 `tests/outputs/` 与 `results/multiview_data/<image_id>/` 约束。

## Goals / Non-Goals

**Goals:**

- 用离散断边而非有限 penalty 保证 cap 前不存在跨缝路径
- 在头皮曲面上求解真实切向 PDE，并提升为体积 PDE 的根部边界
- 用曲面坐标统一生成根点与根部前缀，保证贴附和连续离面
- 用小规模合成测试证明侧别、贴附、端点和符号不变性
- 保持当前默认重建行为可回退

**Non-Goals:**

- 不在本 change 中运行 `10,000` 根或 `128³` 全量重建
- 不优化 KMeans、散度、噪声、平滑或最终 trim
- 不从单张 front 猜测完整隐藏后脑勺真实发缝
- 不在首轮实现六分量 `Q` 张量体素 PDE

## Decisions

### 使用 cut graph 表示发缝拓扑

从头皮三角网格构造顶点邻接图，按发缝曲线的有符号曲面距离给顶点标注左右侧。根部 cap 之外，删除标签相反且穿越零水平集的边；cap 内保留经过平滑门控的绕端点邻接。首轮冒烟在规则平面和半球网格上验证该表示，避免先受真实网格噪声影响。

选择断边而不是提高 PDE penalty，因为断边能够从离散可达性上排除跨缝解。保留 penalty 仅可作为方向正则，不能作为拓扑保证。

### 求解标量势 PDE 并恢复切向根流

首轮在每个 cut graph 图册上求解带 Dirichlet 锚点的离散 Laplace/Poisson 势 `ψ`，再以曲面梯度和发缝外法向构造切向根流。线性系统使用稀疏 SPD 算子；输出残差和强边界误差。相比直接求三分量切向向量，该方式更容易在冒烟阶段验证算子、可达性和端点行为。

后续接线阶段将切向场作为现有三维 screened-Poisson 的根部薄层强边界，仍然是真实 PDE，而不是 EDT 或 Gaussian 替代。

### 用曲面薄层坐标生成根部前缀

每个根部状态保存表面点、单位法向、侧别和目标离面高度。前缀点采用 `x_j=s_j+h(j)n_j` 生成，其中 `s_j` 沿同侧切向场移动，`h(j)` 为单调且一阶连续的离面曲线。该构造替代对已生成点列做独立最近点吸附。

### 首轮实现保持独立并以测试驱动

通用算法放入 `lib/recon_strategy/`，合成冒烟放入 `tests/`。在 S0–S3 全部通过前，不修改 `run_pde_multiview.py` 主入口。S4 接线前必须单独对将修改的现有符号执行 GitNexus upstream impact。

## Risks / Trade-offs

- [真实头模发缝投影不经过现有网格顶点] → 使用最近面重心坐标采样，并在 S4 前增加曲线到曲面距离诊断
- [cut graph 的粗网格可能在窄弯曲发缝处漏断边] → 同时检查边端点符号和边段与零水平集相交，断言跨缝边数为零
- [端点 cap 过短形成硬转角，过长延伸发缝] → cap 长度使用曲面公制并在 S2 检查转角与侧别
- [标量势的梯度不能完全表达复杂旋涡发流] → 它只负责根部薄层；离开薄层后平滑混合现有三维 PDE 场
- [GitNexus 索引当前过期且自动刷新失败] → 修改现有符号前仍调用 impact 并报告不确定性；新模块保持低耦合

## Migration Plan

1. 新增独立 cut graph、表面 PDE 和根部薄层模块
2. 完成 S0–S3 后新增默认关闭的 CLI 接线
3. 仅运行 256 根、30 点的 S4 真实冠部冒烟
4. 若任一硬不变量失败，关闭新 flag 即回退现有基线
5. 后续全量评估必须作为独立 change 执行

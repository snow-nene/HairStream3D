## Context

分区 screened-Poisson 已在六邻域离散算子中删除跨标签通量，但 RK4 仍通过普通三线性插值查询方向，并在积分后叠加 clumping、碰撞、domain recovery 等修正。当前 64³ 样例中有 7.82% 的导出发丝进入非根部分区，说明 PDE 隔离不能自动保证轨迹隔离。

## Goals / Non-Goals

**Goals:**

- 每根发丝以根点标签作为整个生命周期内不可变的分区归属。
- 方向查询只插值根部分区内的场值，避免界面两侧被三线性插值重新混合。
- 每次最终候选更新后检查标签；跨区时回退到当前线段上最后一个合法点。
- guide strand 和普通发丝的聚束关系保持同分区。
- 记录足以验证最终违规率为零的诊断指标。

**Non-Goals:**

- 不重新设计二维 strand/depth 分区。
- 不改变二维标签到三维体素标签的投影方式。
- 不把两个分区变成独立占据体，也不解决所有发缝可见性问题。
- 本变更不修改未显式启用分区标签的默认重建结果。

## Decisions

1. **根点标签使用最近邻采样并保持不变。** 标签是离散类别，不能使用线性插值。启用分区门禁时，所有参与积分的根点必须取得正标签，否则立即拒绝运行，而不是静默回退到连续 PDE。

2. **方向场采用标签归一化插值。** 对每个分区分别对 `field * mask` 和 `mask` 做三线性采样，再以前者除以后者，并按根点标签选择结果。普通三线性插值会在界面两侧混合方向；纯最近邻方向又会引入体素锯齿，因此不采用这两种方案。

3. **候选越界采用线段二分回退。** 每轮所有碰撞、聚束和域修正完成后，对 `step_origin -> candidate` 做固定次数二分，找到原分区内最远的合法点。相比直接冻结在上一步，该方法保留沿界面切向的有效位移；相比沿标签梯度投影，它不依赖离散标签的不可微法向。

4. **RK4 中间查询仍绑定根标签。** `k1` 到 `k4` 都使用同一根标签进行标签归一化插值，即使临时采样点靠近界面，也不会读到另一侧方向。最终候选门禁负责几何不越界。

5. **聚束只匹配同标签 guide。** 保留现有 guide 选择流程，但在全体根点选择最近 guide 时将异标签距离置为无穷；若某个活动分区没有 guide，则明确报错。

6. **分区能力保持显式可选。** 只有传入三维标签体时才启用标签查询、候选回退和同区聚束；否则走现有代码路径，以便进行严格 A/B 回归。

## Risks / Trade-offs

- [边界附近同标签插值权重过小，方向不稳定] → 设置最小有效权重，低于阈值时进入已有 low-field/fallback 诊断，不读取异区方向。
- [频繁二分回退使发丝贴在界面或变短] → 记录回退次数、首次回退步数和最终有效长度，并保留切向位移。
- [某个分区在 guide 采样中没有代表] → 在积分前验证每个根部分区至少存在一个 guide，失败时中止并报告标签计数。
- [碰撞或 silhouette 回滚再次改变候选] → 将分区门禁放在所有候选修正之后、写入发丝数组之前。
- [三维标签本身错误] → 本变更只保证遵守标签，不宣称标签等价于真实三维拓扑；继续保存越界热点用于后续修正标签提升。

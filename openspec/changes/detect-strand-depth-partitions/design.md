## Context

默认重建将多视图 `strand_map` 提升为三维方向边界后，在一个连续体积域内求解方向场。正面 `strand_map` 的 Sobel 散度仅调节 RK4 的随机发散和 guide 聚束，不能表达无向线场的跳变边界。第一阶段需要在不接触默认入口的前提下，判断图像证据是否足以产生稳定的内部阻隔线和分区。

## Goals / Non-Goals

**Goals:**

- 使用 `strand_map + depth_map + seg` 生成与方向符号无关的突变置信图。
- 区分方向突变、深度突变、融合突变和头发外轮廓。
- 从候选内部阻隔线生成连通分区标签及面积统计。
- 所有正面诊断叠加在 `raw_img.png`，已有发缝 mask 仅用于事后评估。
- 以隔离输出支持人工判断是否值得进入分区 PDE。

**Non-Goals:**

- 第一阶段不修改 `run_pde_multiview.py`、PDE 求解器或现有全量结果。
- 不把图像外轮廓误称为内部发缝。
- 不承诺一次阈值即可泛化到所有发型。
- 不在人工确认前执行完整分区 PDE 重建。

## Decisions

1. **用双角表示无向线场。** 将二维单位方向角写为
   \(q=(\cos 2\theta,\sin 2\theta)\)，用邻域双角向量夹角的一半度量线方向差。这样 \(d\) 与 \(-d\) 等价，不会把编码符号翻转当成发缝。直接对 RGB 或 \(\theta\) 做 Sobel 会受到环绕和符号歧义影响，因此不采用。

2. **方向和深度分别归一化后再融合。** 在 `seg` 腐蚀后的内部区域计算多尺度轴向方向差；深度采用 mask-aware Gaussian 平滑后计算邻域相对跳变。两个分量按内部有效像素的稳健分位数归一化，输出独立热图及融合分数，避免深度量纲支配方向证据。

3. **边界候选采用多阈值审计。** 首轮同时输出若干固定分位数阈值，不用已有发缝 mask 调参。每个阈值经过小尺度闭运算、去除短小连通边缘和外轮廓抑制，便于检查稳定性。

4. **分区采用阻隔后的连通分量。** 从 `seg` 中扣除膨胀后的内部边缘，计算连通分区并合并过小区域。该方法故意保持可解释性：如果候选边缘不能真正切开区域，报告应明确显示仍为单区，而不是强制制造看似合理的分割。

5. **已知发缝只做盲后评估。** 检测完成后计算发缝 mask 附近的边缘召回、候选边缘落入发缝邻域的精度和各阈值分区数；检测函数不得读取发缝 mask。

6. **第二阶段以人工门禁为前置条件。** 只有候选边缘在原图上位置合理、不是纹理噪声且能形成稳定分区，才设计分区 Connection Laplace–Beltrami/PDE 接入。

7. **用标签门控离散通量实现严格分区。** 将二维标签通过 front 相机投影提升为三维标签 \(\ell_i\)。有限差分邻接权重改为 \(a_{ij}\mathbf 1[\ell_i=\ell_j]\)，不同标签之间不组装扩散通量。该方法不需要挖空发缝体素，且比内部界面的软法向惩罚更严格。

8. **分区是显式可选能力。** 新参数只支持真实 `screened_poisson`；未传入标签时求解器沿用原算子。二维标签中的空带和背景使用最近非零标签补全后再提升，保证三维 PDE 域内不存在标签 0。

## Risks / Trade-offs

- [方向图本身在发缝处被网络平滑] → 同时检查深度跳变；若两者都无信号，应判定图像证据不足而不是强行分区。
- [发尾卷曲产生大量真实高梯度] → 抑制外轮廓并报告区域面积，首轮不把所有高梯度都解释为发缝。
- [深度图尺度或空洞造成伪边缘] → 使用 mask-aware 平滑、相对跳变和有效邻域筛选。
- [阻隔线不闭合导致仍为单区] → 原样报告并输出多阈值对照，后续可考虑带端点约束的最短路径，而不是在本轮隐式补线。
- [图像分区不等价于三维拓扑分区] → 第一阶段仅验证二维证据；三维提升和跨视图一致性留给人工通过后的第二阶段。
- [正面投影会把背面体素也分成左右两区] → 本轮把它作为可解释的二分先验，并在 `fusion_debug.npz` 保存完整三维标签；后续再用多视图一致性修正。
- [PDE 分区后 RK4 仍可能跨区] → 将 PDE 场隔离与积分轨迹隔离设为两道独立门禁，本轮不把前者误报为最终发丝已分区。

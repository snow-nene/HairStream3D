## ADDED Requirements

### Requirement: 局部发缝层必须保留全局造型
系统 MUST 以既有 v30 发束作为不可变导向，并仅对新增的发缝局部发束生成根区修正；交接区之后的新增发束 MUST 与其匹配导向尾段重合。

#### Scenario: 交接后的尾段不变
- **WHEN** 局部发缝层完成一根发束与 v30 导向发束的交接
- **THEN** 交接点之后对应点的最大位置偏差为数值容差内的零

### Requirement: 根区必须形成稳定的左右分岸
系统 MUST 从发缝两岸均衡采样根点，并在配置的根部薄层内保持每根发束的有符号侧别，不得跨越发缝中心线。

#### Scenario: 两岸均衡且根层不跨岸
- **WHEN** 输入同时包含有效的左右岸候选根点
- **THEN** 输出两岸发束数量差不超过一根，且根部薄层跨岸率为零

### Requirement: 根点必须贴合头皮
系统 MUST 将新增发束根点放置在头皮表面法向的配置偏移范围内，并保证交接前根段不穿入头模，同时报告根点到头皮表面的距离及根段有符号净空统计。

#### Scenario: 根部贴面门禁
- **WHEN** 输入头部网格可用于最近表面查询
- **THEN** 输出根点到头皮表面的中位距离不大于 1 mm，且交接前根段穿模点数为零

### Requirement: 根区侧向开口必须受限
系统 MUST 在离根目标弧长内限制相对发缝的侧向扩张，并以连续权重将该约束衰减到交接区。

#### Scenario: 30 mm 开口增长受控
- **WHEN** 系统对输入发束计算根部和 30 mm 弧长处的两岸中位开口
- **THEN** 30 mm 开口不大于根部开口的 1.5 倍

### Requirement: 实验必须可复现且与生产链路隔离
系统 MUST 通过 `scripts/recon_3d/` 下的显式实验入口运行，默认不改变现有 PDE 重建行为，并将所有生成结果写入对应 Image ID 的 `results/multiview_data/<image_id>/pde_governance/` 子目录。

#### Scenario: 运行独立实验
- **WHEN** 用户提供 v30 PLY、发缝拓扑 NPZ、头部网格和输出实验名
- **THEN** 系统生成独立 layer PLY、合并 PLY 和 JSON 指标，且不覆盖任一输入文件

### Requirement: 质量指标必须支持失败定位
系统 MUST 输出结构化质量指标，至少包含采样数量、匹配距离、根点贴面距离、根层跨岸率、分弧长开口、两岸覆盖率、交接角和尾段最大偏差。

#### Scenario: 指标不满足门禁
- **WHEN** 任一质量指标超过配置阈值
- **THEN** JSON 明确记录失败门禁及实测值，脚本以非零退出状态结束但保留实验产物

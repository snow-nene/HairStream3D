# 左侧缺口根点审查

固定 v32 头模、原图 front 相机、左侧 Flux seg 和当前长度证据，对最终左侧最大缺口逐根检查。

最大连通缺口为约 9,388 个中心线像素，世界坐标范围约 `x=0.0415..0.0986 m`、`y=1.6167..1.8050 m`、`z=-0.0743..0.1029 m`。在该缺口投影范围内有 616 个候选根：

| 状态 | 根数 |
| --- | ---: |
| 局部积分达到长度预算 | 72 |
| 被原图 front 非头发语义否决 | 430 |
| 没有未截断长度证据 | 114 |

侧视共同否决关闭后，这个区域仍不能得到完整覆盖，因为 430 个根点会落到原图 front 的可见非头发区域。原图是唯一 front 真值，因此不能直接放行这些根。114 个根的长度证据缺失属于数据支持不足，也不能用截断前缀填充预算。

这说明左侧缺口的主因是**跨视角几何/相机/seg 不一致**：左侧 Flux 图把一大片区域标成头发，但这些候选根投影到原图后对应脸部或背景。关闭侧视先验只能改善后侧，不能解决左侧；继续增加左侧根数量会重复触发 front 守卫。

当前不应关闭 front 守卫，也不应把左侧 Flux 区域当作隐藏头皮真值。下一步应做左侧相机与原图的独立对应校准，并检查左侧 Flux seg 的轮廓是否包含了头部/背景；只有在留出验证通过后，才可调整左侧根点投影。现有 front 相机重拟合候选留出误差更差，不能直接替换。
